# Real onboarding evidence records

Place only **sanitized, permission-compatible** JSON records here.

The directory is intentionally empty at project start. Do not add a synthetic record just to make the report look populated; synthetic fixtures live in `../fixtures/` and are excluded from the default aggregate.

Before committing a record, follow `../README.md` and `../../../docs/product_validation.md`. Prefer anonymized participant IDs and never commit credentials, proprietary capability definitions, customer data or unsanitized interview notes.
